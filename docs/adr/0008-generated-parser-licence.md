# ADR 0008: Licence of the shipped generated parser

The parser code generated by `antlr-ng` that ships in the npm package (`dist/generated/`,
compiled from `src/generated/`) is released under the project licence, MIT. This closes the
open owner decision of [ADR 0005](0005-packaging-and-release.md) and unblocks release 0.2.0.

## Context

- `src/generated/` is produced by `antlr-ng` 1.0.10 from our own grammars
  `grammar/MdTemplateLexer.g4` and `grammar/MdTemplateParser.g4` (ADR 0002), is committed, and
  is compiled into `dist/generated/`, which the package ships.
- The generated files carry no licence header (no "license" or "copyright" text in
  `src/generated/`). They call the `antlr4ng` runtime (BSD-3-Clause).
- Neither `antlr-ng` nor `antlr4ng` states a licence for generated output. The ANTLR
  project's usual position is that generated code belongs to the grammar author. This was not
  confirmed for `antlr-ng`.
- ADR 0005 and `THIRD_PARTY_NOTICES.md` recorded the question as an open owner decision that
  blocked the first `npm publish`.

## Decision

- **Release parser is MIT.** The owner decided on 2026-10-30 that the generated parser code
  shipped in `dist/generated/` (the output of `antlr-ng` from the two grammars) is released
  under the MIT licence of this project (`LICENSE`).
- This is an owner decision, not a legal opinion. No licence header is added to the generated
  files (they are regenerated by `pnpm run gen:parser` and checked by `pnpm run check:parser`,
  so a hand edit is not allowed).
- `THIRD_PARTY_NOTICES.md` states the decision in "Generated or derived material".
- The `antlr4ng` runtime stays BSD-3-Clause and is still listed as a runtime dependency. This
  decision does not change it.

## Consequences

- The release is no longer blocked on this item.
- `THIRD_PARTY_NOTICES.md` and ADR 0005 no longer list the item as open.
- If `antlr-ng` or ANTLR later state a different position on generated output, a new ADR must
  supersede this one before the next release.
- `antlr-ng` stays a build-time dependency and is not shipped.

## Alternatives considered

| Option                                           | Pros                                                     | Cons                                                         | Verdict    |
| ------------------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------ | ---------- |
| Generated parser is MIT (project licence)        | One licence for our code, matches ANTLR's usual position | No upstream statement for `antlr-ng` output                  | **Chosen** |
| Generated parser is BSD-3-Clause (as `antlr-ng`) | Strictest reading                                        | Mixed licences in `dist/`, no upstream statement requires it | Rejected   |
| Do not ship the generated parser                 | No question                                              | The package cannot work without it                           | Rejected   |
| Leave the decision open                          | No commitment                                            | Blocks the release                                           | Rejected   |
