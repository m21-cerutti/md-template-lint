## Generated code shipped in `dist/`

| Item                                                                  | Origin                                                                                                                                | Licence                                                                       |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `dist/generated/*.js` and `*.d.ts` (lexer, parser, listener, visitor) | Compiled from `src/generated/`, which `antlr-ng` 1.0.10 generates from our own `grammar/MdTemplateLexer.g4` and `MdTemplateParser.g4` | **MIT** (this project's licence), owner decision of 2026-10-30, see ADR 0008. |

The grammars are our work (MIT, see `LICENSE`). The parser code generated by `antlr-ng`
from them and shipped in the package (`dist/generated/`, compiled from `src/generated/`)
is released under the MIT licence of this project. This is the owner decision of
2026-10-30 ("Release parser is MIT"), recorded in
[ADR 0008](docs/adr/0008-generated-parser-licence.md). The generated files carry no
licence header (checked: no "license" or "copyright" text in `src/generated/`). They call
the `antlr4ng` runtime, which stays BSD-3-Clause (above) and is not part of this
decision. `antlr-ng` itself is not shipped.

13.1.0, `stringtemplate4ts` 1.0.9, `unicode-properties` 1.4.1) are MIT on npm and are
not shipped either.

## Findings

- `antlr-ng`: the npm metadata says MIT, but the license file in the npm tarball and
  the GitHub repository both say BSD-3-Clause. We treat it as BSD-3-Clause, the
  stricter of the two. It is a dev dependency, so the package does not redistribute
  it.
- `antlr4ng`: npm, the shipped file and the repository text agree on BSD-3-Clause.
  GitHub only fails to classify the file. Redistribution keeps the copyright notice
  and the three clauses. This file is that notice.
- MIT, BSD-3-Clause and ISC are compatible with distributing md-template-lint under MIT.

## Open owner decisions

- The licence of the `antlr-ng` generated output is decided: the owner decided on
  2026-10-30 that the shipped parser is MIT (see "Generated code shipped in `dist/`" and
  [ADR 0008](docs/adr/0008-generated-parser-licence.md)). Neither `antlr-ng` nor
  `antlr4ng` states a licence for generated output; this is an owner decision, not a
  legal opinion. No owner decision is open on this item.
- The `antlr-ng` npm `license` field (MIT) conflicts with its license file
  (BSD-3-Clause). This could be reported upstream. It does not block us.
